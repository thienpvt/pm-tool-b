<interfaces>
RoiResult = { status: 'insufficient' } | { status: 'ok'; percent: number }.

computeExpectedRoi(sumExpectedBenefitsVnd, approvedNetVnd, hasExpectedRow): insufficient when !hasExpectedRow OR approvedNetVnd &lt;= 0; else percent = (sumExpected - approvedNet) / approvedNet * 100.

computeActualRoi(sumActualBenefitsVnd, actualSpendVnd, allActualsPresent, hasBenefitRow): insufficient when !hasBenefitRow OR !allActualsPresent OR actualSpendVnd &lt;= 0; else percent = (sumActual - actualSpend) / actualSpend * 100. Complete inputs that equal spend yield percent 0 with status ok — distinct from insufficient.

getProjectRoi(projectId, actor, fiscalYear): assertProjectAccess; listFiscalBudgets then filter fiscal_year; approved_net = sum(Number(approved) + sumAdjustmentsVnd(id)); actual_spend = sum(Number(actual_amount_vnd)); list financial benefits for that year; expected = computeExpectedRoi(sum expected_vnd, approved_net, rows.length &gt; 0); actual = computeActualRoi(sum of non-null actuals, actual_spend, rows.every(r =&gt; r.actual_vnd !== null), rows.length &gt; 0). Never substitute 0 for a missing actual_vnd in the sum used for the completeness check.

parseBenefitType(value): COST_SAVING | REVENUE | PRODUCTIVITY else ValidationError('benefit_type').

financial-benefits.repo: listFinancialBenefits(projectId); listFinancialBenefitsForYear(projectId, fiscalYear); getFinancialBenefitInProject(projectId, id); insertFinancialBenefit; updateFinancialBenefit(projectId, id, patch) where patch.actual_vnd may be number | null.

nonfinancial-benefits.repo: listNonfinancialBenefits; getNonfinancialBenefitInProject; insertNonfinancialBenefit; updateNonfinancialBenefit (actual_text optional).

createProjectBenefit(projectId, actor, body): assertProjectWriteAccess; if body.kind === 'financial' insert expected via parseNonNegativeVnd; actual_vnd only when 'actual_vnd' in body (null stays null); unique 23505 or pre-check → ConflictError; auditLog entity_type financial_benefit. if kind === 'nonfinancial' require trimmed group_name, measure, target; optional actual_text; no numeric parse; auditLog entity_type nonfinancial_benefit. else ValidationError('kind').

patchProjectBenefit: write gate; financial patch may set expected_vnd and/or actual_vnd (null allowed); nonfinancial patch may set actual_text. Missing id → 400 at route.
