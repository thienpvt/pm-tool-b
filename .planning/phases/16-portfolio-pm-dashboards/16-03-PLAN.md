<interfaces>
resolveCurrentPeriod(periods, todayIsoDate): period where start_date &lt;= today &lt;= end_date, else the period with the greatest start_date, else null.

isDueInUpcomingOrOverdue(dueDate, todayIsoDate): false if dueDate null/empty; overdue when dueDate &lt; today; upcoming when dueDate &gt;= today and dueDate &lt;= addUtcDays(today, 7) using the same UTC date arithmetic as lib/services/raid-masters.service.ts addUtcDays.

getPmDashboard(actor): if actor.company_id === null throw ForbiddenError; if !hasRole(pm) and !hasRole(cpmo) throw ForbiddenError. stored = getDashboardFilters(actor.user_id, 'pm'); filters = parseDashboardFilters(stored.filters). projects = listProjects(actor.company_id, { pmUserId: actor.user_id }) from projects.repo; attach pm_user_id via getActivePrimaryAssignment; filtered = applyDashboardFilters(projects, filters); assignedIds = Set of filtered ids.

Weekly: listWeeklyPeriods(companyId) from weekly-periods.repo (not weekly-reports.service listWeeklyPeriods which asserts company on actor only — repo is enough); period = resolveCurrentPeriod(periods, today UTC YYYY-MM-DD); shells = period ? listPeriodShellsRepo(companyId, period.id).filter project_id in assignedIds : []; weekly actions = shells with status not_submitted or draft mapped to { project_id, report_id, period_id: period.id, period_display_name: period.display_name, due_at: shell.due_at, status: shell.status, overdue: isWeeklyReportOverdue(status, due_at, now), href: `/projects/${project_id}/weekly-reports/${report_id}` }. Import isWeeklyReportOverdue from weekly-reports.service. Do not import weekly-tracking.service.

Milestones: upcoming = listUpcomingMilestones(companyId); overdue = listOverdueMilestones(companyId); union by milestone id; keep project_id in assignedIds; each row { project_id, milestone_id, name, plan_end, adjusted_end, kind: 'upcoming' | 'overdue', href: `/projects/${project_id}/milestones` }. If a row appears in both lists, kind overdue wins.

RAID: records = listHighOpenRaid(companyId).records filtered to assignedIds and isDueInUpcomingOrOverdue(due_date, today); councilIds = Set of listTechnologyCouncilIssues(companyId) ids; each row { project_id, entity_type, id, code, due_date, has_technology_council: entity_type === 'issue' && councilIds.has(id), href: `/projects/${project_id}/raid` }.

Return { filters, projects: filtered list rows (same fields as portfolio list), actions: { weekly, milestones, raid } }. No response cache.

GET /api/dashboards/pm = withAuth (not withCpmo). Inside handler: null company_id ForbiddenError; require hasRole pm or cpmo; return NextResponse.json(await getPmDashboard(actor)).
