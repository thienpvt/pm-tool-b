getPeriodTracking(companyId, periodId, actor, filters): assertCompanyWrite(actor); if actor.company_id !== companyId throw ForbiddenError; period = getWeeklyPeriodByCompany(companyId, periodId) else NotFoundError('Not found', 'weekly_period'); shells = listPeriodShellsRepo(companyId, periodId); now = new Date(); council issues = listTechnologyCouncilIssues(companyId); map each shell to a tracking row with overdue = isWeeklyReportOverdue(status, due_at, now), rag = shell.rag (version join), has_technology_council_issues from the live project_id set, identity/PM from the extended join; counts from that full mapped list; then apply filters to rows only.

AND-combine present keys. status overdue keeps rows where overdue is true (draft/not_submitted past due), not rows whose stored status string is overdue.

PeriodTrackingRow: project_id, report_id, name, project_code, stage, status, overdue, rag, first_lateness, latest_version, pm_user_id, pm_display_name, has_technology_council_issues.

PeriodTrackingCounts: obligated, not_submitted, draft, submitted, overdue, late.

listPeriodShellsRepo(companyId, periodId): JOIN weekly_periods wp ON wp.id = wr.period_id AND wp.company_id = companyId; JOIN projects p ON p.id = wr.project_id; LEFT JOIN weekly_report_versions wv ON wv.report_id = wr.id AND wv.version = wr.latest_version; LEFT JOIN project_pm_assignments pma ON pma.project_id = wr.project_id AND pma.role = 'primary' AND effective_from &lt;= CURRENT_DATE AND (effective_to IS NULL OR effective_to &gt; CURRENT_DATE); LEFT JOIN users u ON u.id = pma.user_id; WHERE wr.period_id = periodId; SELECT existing PeriodShellListRow fields plus p.name, p.project_code, p.stage, pma.user_id AS pm_user_id, u.display_name AS pm_display_name.
