# Phase 4 Plan 05: Gap Closure — Leftover Access Gates and Two Live IDORs

## Objective

Close the four gaps found by verification. Two are refactor debt (CONTEXT explicitly committed
both to the service layer); two are **live security bugs** in routes the sweep plan missed.

This plan exists because the sweep plan (04-03) was scoped to project *sub-resources* and
missed (a) the parent `projects/[id]/route.ts` itself, (b) the three *nested* budget-item
routes, and (c) two routes sitting under `portfolio/` and `programs/` that take a `project_id`
and were never given an ownership check.

## The four gaps — all verified against the live codebase

1. **`app/api/projects/[id]/route.ts`** still defines its own `checkAccess` (:8-18) and uses it
   (:22, :35, :47). The reference implementation of the unified semantics, but file-local — the
   whole point of `assertProjectAccess` is one canonical home. Replace with a
   `projects.service.ts`.

2. **`app/api/projects/[id]/budget/[itemId]/route.ts`** (+ `/expenses`, + `/expenses/[expId]`)
   each keep a local `authorize(req, projectId)` copy that returns booleans, with handlers doing
   `if (!await authorize(...)) return 401`. A cross-company caller gets **401** here where
   `budget/route.ts` (fixed in 04-03) correctly returns 403. Delete the three `authorize` copies
   and route them through a `budget-items.service.ts` that calls `assertProjectAccess`.

3. **`app/api/portfolio/roadmap/epics/route.ts`** — **live IDOR.** GET is session-gated
   (401 without a session) but then reads `project_id` from the query string and returns that
   project's epic tree with **no ownership check**. Any authenticated user reads any tenant's
   epics. Add `assertProjectAccess`.

4. **`app/api/programs/[id]/project-allocations/route.ts` POST** — **live IDOR (write).**
   `upsertProgramProjectAllocation(programId, project_id, headcount)` runs with no ownership
   check on EITHER side. An authenticated user can allocate another tenant's project into their
   own program. Assert the program's company AND `assertProjectAccess(project_id)` before
   writing.
