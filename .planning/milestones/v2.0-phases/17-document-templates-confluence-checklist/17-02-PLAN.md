parseHttpsUrl(value, field, opts?: { allowEmpty?: boolean }): string | null. Analog lib/fiscal/iso-date.ts. Trim strings. Empty/null/undefined: if allowEmpty return null else ValidationError field required. Non-string: ValidationError. new URL(trimmed); if protocol is not https: throw ValidationError `${field} must use https://`. Also reject trimmed values that start with data:. Return trimmed original string on success.

CHECKLIST_STATUSES = none, drafting, pending_approval, approved, not_applicable.

rejectBinaryFields(body): if body has any of file, content, blob, attachment, data as own keys, throw ValidationError File upload not allowed on that key.

assertChecklistPatchRules(body, status):
- approved: parseIsoDate(approved_at, 'approved_at'); approved_by is number or nonempty trimmed string else ValidationError approved_by; confluence_url via parseHttpsUrl without allowEmpty
- not_applicable: nonempty trimmed na_reason else ValidationError na_reason
- pending_approval: parseHttpsUrl confluence_url without allowEmpty
- none or drafting: parseHttpsUrl confluence_url with allowEmpty
- unknown status: ValidationError status

createTemplateVersion(actor, body): assertCompanyWrite; catalog must exist in actor.company_id else NotFoundError; template_url = parseHttpsUrl(body.template_url, 'template_url'); name/document_type/guidance strings; effective_date via parseIsoDate; next version = max(existing versions for catalog_id)+1 or 1; repo retires current (retired_at = now() WHERE catalog_id AND company_id AND retired_at IS NULL) then INSERT; auditLog entity_type document_template action version_insert. Return new row.

listEffectiveTemplates(actor, catalogId?: number): same Viewer-only 403 as catalog list; query retired_at IS NULL AND effective_date <= CURRENT_DATE ORDER BY version DESC; if catalogId set, that catalog only, limit 1; else one effective row per catalog_id (DISTINCT ON catalog_id / grouped max version in service).

getTemplate(actor, id): company match; return row even when retired_at is set (D-05 history).

retireTemplate(actor, id): assertCompanyWrite; set retired_at = now() if currently null; auditLog action retire.
