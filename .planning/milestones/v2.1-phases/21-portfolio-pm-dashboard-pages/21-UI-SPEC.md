# Phase 21 — UI Design Contract

> Visual and interaction contract for CPMO spec portfolio dashboard (`/dashboards/portfolio`) and PM action dashboard (`/dashboards/pm`). Generated by gsd-ui-researcher; consumed by gsd-ui-checker, gsd-planner, gsd-executor.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | shadcn |
| Preset | `b2fA` — base-nova, neutral, Geist sans, lucide, radius default |
| Component library | Base UI (shadcn base-nova) |
| Icon library | lucide-react (same as Sidebar) |
| Font | Geist Sans (`--font-sans` in `app/globals.css`) |

**Installed components to use:** `Card` (prefer `size="sm"`), `Button`, `Badge`, `Table`, `Select`, `Input`, `Separator`, `Sheet` (mobile only if needed). Toasts via `sonner` (already wired in Sidebar).

**Do not install:** chart libraries, Excel/PDF client libs, new shadcn blocks, third-party registries.

## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon–label gaps, badge padding |
| sm | 8px | Compact table cell padding (`p-2`), inline control gaps |
| md | 16px | Default section gaps (`gap-4`), Card internal spacing |
| lg | 24px | Page header margin-bottom, filter bar padding |
| xl | 32px | Main content horizontal padding on desktop |
| 2xl | 48px | Major section breaks between dashboard zones |
| 3xl | 64px | Unused this phase |

**Exceptions:** Sidebar nav touch targets stay at existing `py-2` (~32px row height). KPI tile minimum height 72px for click targets on drill-down tiles.

**Page shell:** Match v1 portfolio and admin pages — `flex flex-col lg:flex-row min-h-screen bg-slate-50`, main `flex-1 p-4 lg:p-6 lg:p-8 overflow-auto`.

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 14px (`text-sm`) | 400 | 1.5 | Table cells, filter labels, queue rows |
| Label | 12px (`text-xs`) | 600 (`font-semibold`) | 1.4 | Filter field labels, KPI subtitles, section eyebrows |

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `bg-slate-50` (`oklch` via `--background` on cards is white) | Main content canvas |
| Secondary (30%) | `bg-white` cards, `bg-[#0f172a]` sidebar | Cards, tables, filter bar chrome |
| Accent (10%) | `blue-600` (`bg-blue-600`, `text-blue-600`, `hover:bg-blue-700`) | Primary buttons, active drill-down tile ring, sidebar active link (existing) |
| Destructive | `red-600` / `red-50` bg | Overdue badges, high-severity RAID rows only |

**Accent reserved for:** Export primary actions, clickable KPI tile hover/focus ring, row link text (`text-blue-600 hover:underline`), active filter "Apply" button, loading spinner border (`border-blue-500`).

**Semantic RAG (charts + badges, not accent):** green `bg-green-100 text-green-700`, amber `bg-amber-100 text-amber-700`, red `bg-red-100 text-red-700`.

**Card styling:** `Card size="sm"` with default shadcn ring; optional `shadow-sm` on KPI row only to match v1 `KpiCardsRow` density without duplicating custom rounded-2xl markup.

## NIT-04 — Fiscal KPI Omission (Locked)

**Decision:** Fiscal budget / ROI / benefit KPIs are **omitted** from the spec portfolio dashboard.

| Rule | Detail |
|------|--------|
| No tiles | Do not render budget, ROI, benefit, or currency-denominated KPI cards |
| No API calls | Do not fetch `/api/portfolio/budgets` or embed v1 budget hooks |
| No fields | `PortfolioKpis` has six spec fields only — UI must not invent fiscal columns |
| Redirect note | Optional muted footnote on portfolio page: "Budget and fiscal metrics are on Portfolio Budget (`/portfolio/budget`)." — single line, `text-xs text-muted-foreground`, not a tile |
| Test gate | Component test asserts KPI row DOM contains none of: `budget`, `ROI`, `benefit`, `$`, `₫`, `VND` |

**Source:** 21-CONTEXT D-14, D-15; Phase 16 D-14; REQUIREMENTS NIT-04.

## Component Contracts

### KPI tiles (portfolio)

Six tiles bound to `kpis` from GET `/api/dashboards/portfolio`:

| Tile label | Field | Drill-down key | Clickable |
|------------|-------|----------------|-----------|
| Active projects | `active_count` | — | No |
| On track | `on_track_count` | — | No |
| Watch / act | `watch_act_count` | — | No |
| Overdue milestones | `overdue_milestone_project_count` | `overdue_milestones` | Yes |
| High open RAID | `high_open_raid_count` | `high_raid` | Yes |
| Technology council | `technology_council_count` | `technology_council` | Yes |

**Tile anatomy:** Label (`text-xs font-semibold text-slate-600`), number (`text-3xl font-semibold`), optional subtitle. Clickable tiles: `cursor-pointer`, `ring-2 ring-blue-600` when selected, `hover:bg-slate-50`.

**Layout:** `grid grid-cols-2 sm:grid-cols-3 xl:grid-cols-6 gap-4`.

### Charts (portfolio)

CSS horizontal bar charts from `charts.by_stage` and `charts.by_rag`. No chart npm package.

- Bar height 8px, gap 8px between rows, label `text-xs` left, count right
- Stage order: L0, L1, L2, L3, L4, L5
- RAG colors per semantic tokens above

### Filter bar (both pages)

AND keys (21-CONTEXT D-06): `portfolio_year`, `program`, `unit`, `pm_user_id`, `stage`, `status`, `rag`, `type`, `weekly_report_enabled`.

| Control | Pattern |
|---------|---------|
| Layout | `flex flex-wrap gap-2 items-end` inside white Card or bordered bar |
| Fields | shadcn `Select` or native `<select>` styled compact; boolean as Select Yes/No/All |
| Actions | **Apply filters** (primary) refetches GET; **Clear filters** POST clear then refetch; **Reset defaults** POST defaults |
| Persist | PUT `/api/dashboards/{portfolio\|pm}/filters` on apply; load from GET filters on mount |
| Density | Label `text-xs`, control height 32px (`h-8`) |

Changing any filter and clicking Apply refetches dashboard GET with persisted filters.

### Tables (compact)

Use shadcn `Table` with existing compact classes:

- `TableHead`: `h-8 px-2 text-xs`
- `TableCell`: `p-2 text-sm`
- Row hover: default muted hover
- Long project names: `truncate max-w-[200px]` with `title` attribute
- Primary link column: project name → `/projects/{id}`

**Portfolio project list columns:** Name (link), Code, Program, Stage, Status, RAG (Badge), PM, Progress %.

**Drill-down tables:** Render rows from `drilldowns[activeKey]`; link via row id fields to project/milestone/RAID screens when `href` or ids present.

**PM queue columns:**

| Queue | Columns |
|-------|---------|
| Weekly | Project, Period, Due, Status (Badge), Overdue flag, Action link |
| Milestones | Project, Milestone, Plan end, Kind (upcoming/overdue Badge), Action link |
| RAID | Project, Code, Type, Due, Tech council flag, Action link |

Action link: `<Link href={row.href}>` with Copywriting labels **Open report** / **View milestone** / **View RAID** (`text-blue-600 text-sm`).

### Export (portfolio only)

Two outline/primary buttons in header: **Export Excel**, **Export PDF**.

- POST `/api/dashboards/portfolio/export` with `{ format: 'xlsx' | 'pdf' }`
- Download blob with server filename; toast success **Export downloaded** or error from Copywriting Contract
- Disable buttons while in-flight; no client-side generation

### Auth & forbidden

- NAV hidden for unauthorized roles (no second authz layer)
- API 403/401: centered main content — spinner while loading, then forbidden panel (see Copywriting Contract)
- Do not redirect like admin; show in-page forbidden state so deep links fail visibly
