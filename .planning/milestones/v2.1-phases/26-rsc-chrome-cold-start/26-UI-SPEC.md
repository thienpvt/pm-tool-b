## Typography

**Contract: PRESERVE EXISTING.** Two weights only — do not add a third weight anywhere in refactored UI (26-CONTEXT D-06).

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 14px (`text-sm`) | 400 | 1.5 | Table cells, form fields, helper text, error messages |
| Label | 12px (`text-xs`) | 600 (`font-semibold`) | 1.4 | Field labels, section eyebrows, count chips |
| Heading | 16px (`text-base`) | 600 | 1.2 | Page title, Card titles, section headers |
| Display | 28px (`text-3xl`) | 600 | 1.1 | KPI tiles, summary count strips (where already used) |

**Weights used:** 400 (body), 600 (labels, headings). Max two weights — enforced.

**Loading shell copy:** `text-slate-400 text-sm` (weight 400).

**Error shell copy:** `text-sm text-slate-600` (weight 400).

**Language:** English labels throughout — match existing Sidebar NAV strings; do not rename labels during chrome extraction.
