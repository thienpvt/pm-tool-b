# Phase 24 — UI Design Contract

> **Preserve-existing contract** for the repo-wide module split. No new screens, no visual redesign, no copy changes. Generated by gsd-ui-researcher; consumed by gsd-ui-checker, gsd-planner, gsd-executor.

**Visual regression definition:** Every listed page route still renders at the **same URL** with the same layout, spacing, typography, colors, and copy as before the split. Regression is detected when a route 404s, redirects unexpectedly, or renders visibly different chrome/content.

**Source:** 24-CONTEXT D-10 (visual contract: preserve existing); MOD-01, MOD-02.

## Typography

**Contract: PRESERVE EXISTING.** Two weights only — do not add a third weight anywhere in moved UI.

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 14px (`text-sm`) | 400 | 1.5 | Table cells, form fields, helper text |

## Component Contracts

**Contract: PRESERVE EXISTING.** No new components, no prop API changes visible to users, no layout refactors.

| Rule | Detail |
|------|--------|
| Move only | Relocate files to `modules/<feature>/{backend,ui}/`; fix `@/` imports |
| Re-export shells | `app/**/page.tsx` and `app/api/**/route.ts` stay as thin delegates |
| No duplication | Do not copy UI trees already under `modules/dashboards|weekly|documents|audit/ui/` |
| Shared UI | Layout, shadcn primitives, brand assets stay in `components/` unless clearly feature-owned |
| Behavior | Identical fetch URLs, form fields, validation messages, toasts, modals |
| Tests | Update import paths; assertions on DOM copy/classes must still pass |

### Executor checklist (per wave)

1. Move backend + UI files for one feature area.
2. Add/update thin `app/` re-exports so URLs unchanged.
3. Run existing Vitest suites; fix import paths only.
4. Manual or scripted smoke: hit representative URLs from Page Inventory table.
5. Confirm Sidebar NAV and forbidden/loading/error panels unchanged for that area.
