<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| credentials.ts → process.env | env values (including stored Jira API tokens) cross into the credential objects |
| credentials.ts → repositories | DB rows (`company_jira_config`, `settings`) cross into the credential objects |
| errors.ts / credentials.ts → routes | normalized error objects and credentials cross to route handlers |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-01 | Information Disclosure | credentials.ts | high | mitigate | Credentials objects never leave the server process; routes pass them to clients only. No `IntegrationError` message embeds a key value — the class carries kind/service/status/cause, and HTTP mapping (plan 03-02) renders fixed strings |
| T-03-02 | Spoofing | credentials.ts | high | mitigate | Per-integration precedence preserved byte-for-byte (INTG-08); the empty-string normalization is the only change, unit-tested and flagged in the commit |
| T-03-03 | Spoofing | verify-credential-cutover.ts | medium | mitigate | Script is read-only (SELECT only, no env mutation); it compares old vs new resolution and fails loudly on mismatch before deletion |
| T-03-04 | Tampering | npm install zod | low | mitigate | Legitimacy gate passed (RESEARCH: no postinstall, verified registry metadata); pinned `^4.3.6` |
| T-03-05 | DoS | withFetchTimeout | medium | mitigate | Timer cleared in `finally` so no process-level hang; caller abort distinct from timeout (kind 'network' vs 'timeout') so a slow call cannot be misreported as a route cancellation |
| T-03-06 | Information Disclosure | IntegrationError.cause | medium | mitigate | `cause` may carry upstream response bodies server-side only; the HTTP mapper never serializes `cause` to the client |

</threat_model>
