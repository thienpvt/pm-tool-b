<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client.ts → *.atlassian.net | outbound HTTPS with Basic auth crosses the boundary |
| Jira API → client.ts | upstream JSON (untrusted) crosses back in and is zod-validated |
| admin body (test route) → resolver | env var NAMES from the request body cross into process.env lookups |
| client.ts → integrationErrorResponse → response body | fixed strings / pass-through status; raw bodies stay in cause |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-17 | Tampering | jira/client.ts | high | mitigate | zod boundary validation (INTG-05); malformed response → logged `IntegrationError{kind:'validation'}` → 502, never partial data |
| T-03-18 | Spoofing | resolveJiraCredentials explicit path | high | mitigate | Admin body names are treated as names only, resolved against process.env by the resolver; no credential value ever travels in a request body |
| T-03-19 | Information Disclosure | lib/api-errors.ts jira branches | medium | mitigate | Upstream message pass-through matches today's behavior; schema/cause details never serialized |
| T-03-20 | Spoofing | cutover (Task 4) | high | mitigate | Read-only script gate BEFORE deletion; mismatch aborts the task; HYG-01 one-commit cutover for bisectability |
| T-03-21 | DoS | jira/client.ts | medium | mitigate | 15s `withFetchTimeout`; timer cleared on success; timeout → kind 'timeout' → 500 string, not a hang |
| T-03-22 | Tampering | jira test route regression | low | mitigate | route.test.ts locks the missing-env diagnostic shape and explicit-config path before cutover |
